## 0. 結論（先取り）

素数 p に対する解の全構造を、2つの明示的な存在条件（族 D・族 G）に**完全に**
帰着させる補題連鎖を証明した（定理 A）。その上で、mod 840 の6例外類への
帰納が破綻する位置を「境界付きテンプレートの合併では剰余類全体を被覆できない」
という不変量として正確に特定し、それを突破するために必要な最小の新補題を
「p+w が類 −1 (mod 4w) の約数を持つ」（F1）または族 D の可解性（F2）と
して定式化した。素朴な予想 H* は計算で反証済み（§4.3）— 例外類の抵抗は
定性的ではなく**一様性**の問題である。

## 1. 定義と既知の部分結果

**定義 1.1.** S(n) :=「4/n = 1/x + 1/y + 1/z が正整数解 x ≤ y ≤ z を持つ」。
S(p) の解全体の集合を Sol(p) と書く。

既知の結果（**出典は記憶に基づく・本セッションでは未検証**。文献照合が必要）:

- (K1) Mordell による剰余類検証: S(n) は n ≢ 1², 11², 13², 17², 19², 23²
  (mod 840) で成り立つ（記憶・未検証）。840 = 2³·3·5·7。
- (K2) Vaughan 型の密度1結果: 例外は密度 0（記憶・未検証）。
- (K3) Elsholtz–Tao 型の解数評価: |Sol(n)| の平均次数下界・点別上界
  （記憶・未検証。本理論では使わない）。
- (K4) Schinzel 仮説 H（素数 k-tuples）を仮定すると予想が従うという folkloric
  主張（記憶・未検証。§5 で本理論の言葉で再説明する）。
- (K5) 計算検証が 10^14 を超える範囲で済んでいる（claim カード記載）。

**検証済みの初等的補題（本セッションで証明）:**

**補題 1.2（スケーリング帰着）.** d ≥ 2 かつ S(d) なら、任意の m ≥ 1 で
S(dm)。よって最小反例は素数である。
証明: 4/d = 1/x+1/y+1/z ⟹ 4/(dm) = 1/(mx)+1/(my)+1/(mz)。強い帰納法。∎

**補題 1.3（p | xyz）.** p 素数、4/p = 1/x+1/y+1/z なら p | xyz。
証明: 4xyz = p(xy+xz+yz)。∎

以下、p は奇素数、解は変数の置換を自由にする。

## 2. 補題連鎖

### 2.1 SFFT パラメタライズ（補題 2.1）

p-divisible な変数を z とし z = pz' と書く（補題 1.3）。このとき

  4/p − 1/(pz') = (4z'−1)/(pz') = 1/x + 1/y

の右辺が2項展開可能である条件は、Simon の factoring trick により

  ((4z'−1)x − pz')·((4z'−1)y − pz') = p²z'²   (★)

と同値。m := 4z'−1、a := mx−pz'、b := my−pz' と置くと、解 ↔ 因子対
(a,b)（a·b = p²z'²、a ≡ b ≡ −pz' (mod m)、x = (a+pz')/m 等）。
a = p^i·σ、b = p^{2−i}·τ（σ·τ = z'²、i ∈ {0,1,2}）と分解する。

### 2.2 中間分岐の消滅（補題 2.2）

**補題 2.2.** gcd(p, m) = 1 なら i = 1 な解は存在しない。
証明: 条件 p·σ ≡ −pz'、p·τ ≡ −pz' (mod m) を p で割ると σ ≡ τ ≡ −z' (mod m)。
σ > 0, τ > 0 の場合: σ = km − z'、τ = ℓm − z'（k, ℓ ≥ 1）と書けて
σ·τ = z'² に代入すると kℓm = z'(k+ℓ)。一方 m = 4z'−1 ≥ 3z' なので
z' = kℓm/(k+ℓ) ≥ 3kℓz'/(k+ℓ)、すなわち k+ℓ ≥ 3kℓ。しかし 3kℓ − k − ℓ > 0
（k=ℓ=1 で 1、以後単調増加）で矛盾。σ < 0, τ < 0 の場合: |σ| = km+z'、
|τ| = ℓm+z' と書けて (km+z')(ℓm+z') = z'² の左辺 > z'² で矛盾。∎
（数値確認: p ≤ 48 の全解 151 個で中間分岐使用例なし。）

### 2.3 構造二分（定理 A — 本成果の中心）

**定理 A.** p 素数、(x,y,z) ∈ Sol(p) とする。p-divisible スロット z = pz'
（m = 4z'−1）について、次の二分が成り立つ:

- **(D) 退化族**: p | m。
- **(G) 一般族**: p ∤ m かつ ∃ σ | z'²: m | σ + pz'。
  このとき σ ≡ −pz' (mod m) が i ∈ {0,2} 分岐の正確な条件であり、
  τ = z'²/σ 側の条件 p·τ ≡ −z' (mod m) は σ の条件から自動的に従う
  （τ ≡ z'²·σ^{−1} ≡ −z'p^{−1} (mod m)、gcd(σ,m) = gcd(pz',m) = 1 を使用）。

逆に各族の条件から解が構成できる（§2.4）。
証明: §2.1 の分解で i=1 が補題 2.2 で消え、i ∈ {0,2} は p で割って
σ ≡ −pz' (mod m) を与える。∎
（数値確認: p ≤ 48 の全解 151 個で二分成立、失敗 0。内訳 D:104, G:47。）

### 2.4 逆構成（補題 2.4 — 各族の明示恒等式）

**(G) の逆構成.** σ | z'²、m | σ+pz'、p ∤ m とする。τ := z'²/σ と置くと
p·τ ≡ −z' (mod m) が成り立ち、

  x := (σ + pz')/m,   y := p(p·τ + z')/m,   z := pz'

は整数解である（(mx−pz')(my−pz') = σ·p²τ = p²z'² で SFFT 逆復元、
1/x+1/y = m/(pz') を確認）。

**(D) の完全特徴付け（補題 2.5）.** p | m のとき j := m/p と置くと、
(★) は σ = jx − z'、τ = jy − z'（自動的に σ ≡ −z' (mod j)）と書け、
解の存在と

  ∃ k, ℓ, j ≥ 1:  p·j = 4z'−1 かつ j·k·ℓ = z'·(k+ℓ)

が同値である。このとき (x,y,z) = (k, ℓ, pz')（の置換）であり、検算は
1/k + 1/ℓ = (k+ℓ)/(kℓ) = j/z'、全体で j/z' + 1/(pz') = (jp+1)/z' = 4/p。
（数値確認: p ≤ 31 の D 族解 60 個で jkℓ = z'(k+ℓ) 成立、失敗 0。）

**系 2.6（単純な十分条件）.** 任意の g, K, L ≥ 1 について
4·g·K·L = p(K+L) + 1 ならば (gK, gL, pgKL) は解。
（補題 2.5 の j = K+L、k = gK、ℓ = gL、z' = gKL の場合。）

### 2.5 族 G の線形テンプレート階層（補題 2.7）

族 G の条件 m | σ + pz' は σ の取り方ごとに「p の線形式の約数条件」に落ちる:

- **σ = 1**: m | pz'+1 ⟺ m | p+4。よって「p+4 が ≡ 3 (mod 4) の約数を
  持つ」ことが十分（z' = (m+1)/4 が自動で整数）。
- **σ = z'²**: m | z'(p+z') ⟺ m | 4p+1。よって「4p+1 が ≡ 3 (mod 4) の
  約数を持つ」ことが十分。
- **一般に σ = z'w（w | z'）**: m | z'(p+w) ⟺ m | p+w。d := m と読むと、
  **(F1): ∃ w ≥ 1: p+w が d ≡ −1 (mod 4w) の約数 d を持つ**
  という形にまとめられる（d = 4z'−1、w | z' が復元条件）。

数値確認（p < 2000 の素数 302 個）: σ=1 経路で 232 個、σ=z'² 経路で 174 個、
合併 271 個が解消。残り 31 個（13, 37, 61, 97, … と例外類外のものを含む）
はより深い σ パターンが担当する — 階層は単一の線形経路では閉じない。

## 3. 6例外類の正体 — 帰納が破綻する正確な位置

### 3.1 被覆の意味論

「剰余類 r (mod 840) がテンプレートで解ける」ためには、進数 {r + 840t} が
テンプレート類の合併に**含まれる**必要がある。単一類 c (mod m) が
r (mod 840) を含む ⟺ **m | 840 かつ r ≡ c (mod m)**。m と 840 が互いに素
だと単一類では絶対に被覆できない（進数が類を横切る）。これが
「境界付きパラメータのテンプレート合併」に本質的な限界を課す。

### 3.2 小 modulus 族 G クラスの合併（計算による確認）

m = 4z'−1 | 840 となるのは m ∈ {3, 7, 15, 35}（z' = 1, 2, 4, 9）のみ。
各 z' で σ | z'² の類 c ≡ −σz'^{−1} (mod m) を全部集めると:

- mod 3: {2}
- mod 7: {3, 5, 6}
- mod 15: {7, 11, 13, 14}
- mod 35: {23, 26, 31, 32, 34}

この合併に落ちない 840 の単元は **24 個**残り、
{1, 79, 109, 121, 151, 169, 211, 289, 319, 331, 361, 379, 421, 499, 529, 541,
571, 589, 631, 709, 739, 751, 781, 799} — **6例外類 {1, 121, 169, 289, 361, 529}
の真の超集合**。例外類は「r ≡ 1 (mod 24)、r ≡ ±1 (mod 5)、r は mod 7 の
平方剰余」という二次的構造を持ち、小さい m の類がすべてこの構造と衝突する。

これが (K1) の Mordell 型検証の正体である: 帰納・テンプレート法は
「複雑さが境界付きの σ パターン（＝p の固定線形式の固定類の約数条件）」で
動いており、その各レベルで被覆できない類の核が上記の二次構造として
不変に残る。**破綻点はここ**: 境界を外して σ（や w, z'）を p に応じて
動かすと個々の素数はすぐ解けるが（次節）、その存在を「類に対して一様に」
言う手段が解析的数論に存在しない。

### 3.3 例外類でも個別には解ける（予想 H* の反証）

事前に登録した安い反証テストの結果:

- **予想 H***（反証前に登録）: 「素数 p が族 G 解を持つ ⟺ p mod 840 ∉ 6例外類」。
- 反証テスト1（前方）: 例外素数 p ≤ 10000（27個: 1009, 1129, 1201, 1801,
  2521, …, 9769）全員が z' ≤ 100000 で族 G 解を持つ → **H* 反証**。
  最小 z' は驚くほど小さい: 1009→3, 1129→3, 1201→8, 1801→3, 2521→12,
  2689→6, 3049→11, 3361→25。
- 反証テスト2（後方）: 非例外素数 p ≤ 400（77個）は全員 z' ≤ 20000 で
  族 G 解を持つ（最小 z' の中央値 1、最大 11）→ こちらは H* と整合。

例: p = 1009 は 4p+1 = 4037 = 11·367 の 11 ≡ 3 (mod 4) が σ=z'² 経路を、
p+w = 1012 = 4·11·23 の 11 ≡ −1 (mod 4·3) が F1 (w=3) 経路を通る。

**結論: 6例外類の「抵抗」とは、個別可解性ではなく、境界付き複雑さの
テンプレート（固定線形式・固定類・固定 modulus）では進数全体を被覆できない
という一様性の欠如である。** 既知の密度1証明（K2）がこの階層を平均で押し
進められるのに対し、最後の6類は「どの有限レベルでも被覆されない」という
二次剰余の不変量として残る。

### 3.4 族 D の側から見た例外類

族 D（系 2.6 型の証明書）は逆に、例外素数に対してパラメータの大きい証明書を
与える傾向がある（g ≤ 600 探索）: 1009 → (g,L,K) = (23, 11, 3700)、
1801 → (41, 11, 6604)、3361 → (29, 29, 32490) と K/p が 3.7〜9.7 に達する
一方、1129, 1201, 2521, 2689, 3049 は g ≤ 600 で証明書なし。族 D の条件
4gKL = p(K+L)+1 は小 modulus に対して周期的でないため、剰余類帰納の
「被覆」の枠組みにそもそも乗らない — 例外類を救済する力はあるが
一様化できない。

## 4. 破綻点の正確な記述

定理 A により、E-S は次と同値である:

> **(†)** すべての素数 p ≥ 3 について、
> (i) ∃ z', σ: σ | z'² ∧ (4z'−1) | (σ + pz')、または
> (ii) ∃ k, ℓ, j: (k+ℓ) | jkℓ ∧ p = (4jkℓ − k − ℓ)/(j(k+ℓ))。

**破綻点: (†) の全称文。** 具体的には、6例外類の素数に対する (i)/(ii) の
存在証明ができない。既存手法が通らない理由:

1. **Dirichlet / Linnik**（固定 AP の素数）: (i) で必要なのは「modulus
   4z'−1 が自由パラメータと共に動き、かつ目標類 −σz'^{−1} が同じパラメータで
   決まる」配置。固定 modulus の理論は適用できない。
2. **Bombieri–Vinogradov**: 類に関する平均は modulus ≤ X^{1/2} まで。
   ここでは modulus が探索自由変数そのもの（≈ X オーダーで動く）なので
   「X に対するレベル X^{1/2}」の枠組み自体が定義しない。
3. **Titchmarsh 型平均**（τ(pL+1) の平均）: 約数の**個数**の平均は出るが、
   約数が「modulus に対する指定類」に入るという制約は平均から落ちる。
4. **Iwaniec 型ふるい**（二次多項式の約数）: 多項式が固定であることが前提。
   σ | z'² という乗法制約と 4z'−1 | σ+pz' という合同制約の三重連動は扱えない。
5. **帰納・テンプレート法（Mordell 型）**: §3.2 の通り、境界付き複雑さでは
   6類が二次剰余の不変量として残る。境界を外すと一様性を失う。

つまり (†) は「動く modulus・動く類・動く乗法制約」の三重連動した
約数存在問題であり、現行の解析的道具はいずれもこの三重連動を扱えない。
これが「density-1 は証明できるのに最後の類が立ちはだかる」構造的理由。

## 5. 最小の新補題

**NL（F1/F2 存在補題）.** 各 r ∈ {1, 121, 169, 289, 361, 529} と
素数 p ≡ r (mod 840) について、次の少なくとも一方が成り立つことを示せ:

- **(F1)** ∃ w ≥ 1: p+w が d ≡ −1 (mod 4w) の約数 d を持つ
  （族 G の σ = z'w サブファミリー）。
- **(F2)** ∃ k, ℓ, j ≥ 1: (k+ℓ) | jkℓ かつ p = (4jkℓ−k−ℓ)/(j(k+ℓ))
  （族 D）。

NL が証明されれば E-S は（補題 1.2 + 定理 A + 補題 2.4/2.5 により）解決する。
逆に、NL の反証は E-S の反証を与える。すなわち NL は E-S と**同値な強さ**で、
しかし対象を「6類に絞った、単一の明示的な約数条件」にまで削ぎ落としている
点が新規性である。

補助的な中間目標（NL より弱く、独立の価値を持つ）:

- (M1) F1 のみで6類が全て賄えるか。cheap falsification（事前登録案）:
  例外素数 p ≤ 10^6 について w ≤ 10^4 の F1 証人を探し、1つでも
  証人不在なら F1 単独は不十分と判定する。
- (M2) 最小証明書パラメータの上界: 例外素数の min max(z',σ) が
  p^{1/2} 以下で常に取れることの証明または反例探索。現時点のデータ
  （min z' ≤ 25 @ p ≤ 3361）は O(log p) 級を示唆する。
- (M3) (K4) の再説明: Schinzel H の下では、σ=1 経路（p+4 の約数）や
  F1 が「p+w の素因数構造」の自由度から従う。本理論の言葉では、
  H は「動く modulus 問題」を素数値多項式の存在に置き換える装置であり、
  この置き換えが無条件に行えないことが破綻点の別表現である。

## 6. Verdict: **ROUTE-LIVE**

根拠:

1. **完全な構造帰着を証明した**（定理 A + 補題 2.4/2.5）: E-S（素数場合）は
   2つの明示的な Diophantine 存在条件の全称文 (†) と同値。連鎖の内部に
   ギャップは残っていない（全補題に証明と数値的境界確認あり）。
2. **破綻点を正確に特定した**: 6例外類は「境界付きテンプレート合併で
   被覆できない類の核」（mod 3, 7, 15, 35 の類の合併から 24 単元の
   超集合として計算で確認）であり、抵抗の本体は個別可解性ではなく
   一様被覆の不可能性である（予想 H* の反証により確定）。
3. **突破に必要な算術的対象を明示した**: (F1)「p+w の −1 (mod 4w) 類の
   約数」または (F2)「4jkℓ−k−ℓ = pj(k+ℓ) 型の表現」。既存手法
   （Dirichlet/Linnik/BV/Titchmarsh/Iwaniec ふるい）がいずれも
   「動く modulus・動く類・動く乗法制約」の三重連動を扱えないことを
   個別に特定した。
4. ただし本成果は E-S の解決ではない。NL は現時点で未解決であり、
   (M1)-(M3) は次の反証・攻撃ステージの入口である。
