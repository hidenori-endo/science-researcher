## 0. 結論（先取り）

**本成果は Erdős–Straus 予想の解決ではない。** さらに 2026-08-23 の再査読で、
初版の中心的な新規性主張2つのうち1つは論理的に誤り、もう1つは先行研究と
実質的に重複していることが判明した。以下は訂正済みの位置づけである。

素数 p に対する解の全構造を、2つの明示的な存在条件（族 D・族 G）に完全に
帰着させる補題連鎖を証明した（定理 A）。この連鎖自体は正しい（再査読で
補題 2.2・定理 A を追検証済み）。ただし**この帰着は Elsholtz–Tao の
Type I / Type II 分類および Bradford の divisor 条件の座標変換であり、
新しい構造定理ではない**（§8）。

その上で、mod 840 の6例外類への帰納が破綻する位置を「境界付きテンプレートの
合併では剰余類全体を被覆できない」という不変量として特定した。この
obstruction も既知である（§8.3）。

突破に必要な補題として「p+w が類 −1 (mod 4w) の約数を持つ」（F1）または
族 D の可解性（F2）を定式化した。**初版はこの NL が E-S と「同値な強さ」だと
主張したが、これは誤りである**。F1 は帰着が生む族 G の真部分族しか扱わない
（§5 訂正、反例は §5.1）。成立するのは `NL ⇒ E-S` の一方向のみ。

素朴な予想 H* は計算で反証済み（§3.3）— 例外類の抵抗は定性的ではなく
**一様性**の問題である。この観察は訂正の影響を受けない。

**2026-08-23 追記（§9）:** 上の穴を本枠組みのまま塞ぎに行った結果、
(a) F1 は決定可能（補題 F）、(b) 必要とされた exhaustion lemma は**偽**、
(c) F1 単独では6例外類を賄えない（p = 5569, 9601 が反例、証明済み）、
(d) 穴の正しい修復は `τ | z'` を `τ | z'²` に広げる **τ 正規形**であり、
これは E-S とちょうど同値、と確定した。ただし (d) の τ 正規形は Lopez
(arXiv:2404.01508, 2024-04) の合同式系の完全化であり、**F1 は同系の型 (B)
そのもの**だった。verdict は ROUTE-KNOWN のまま変わらない。

## 1. 定義と既知の部分結果

**定義 1.1.** S(n) :=「4/n = 1/x + 1/y + 1/z が正整数解 x ≤ y ≤ z を持つ」。
S(p) の解全体の集合を Sol(p) と書く。

既知の結果（初版は「記憶に基づく・未検証」だった。2026-08-23 の再査読で
(K1)/(K3) を文献照合した。照合の範囲と限界は §8.4 に明記する）:

- (K1) Mordell による剰余類検証: S(n) は n ≢ 1², 11², 13², 17², 19², 23²
  (mod 840) で成り立つ。840 = 2³·3·5·7。
- (K2) Vaughan 型の密度1結果: 例外は密度 0（記憶・未照合のまま）。
- (K3) Elsholtz–Tao, *Counting the number of solutions to the Erdős–Straus
  equation on unit fractions*, arXiv:1107.1010 / J. Aust. Math. Soc. —
  |Sol(n)| の平均評価（`N log²N ≪ Σ_{p≤N} f(p) ≪ N log²N log log N`）と
  点別上界。**本理論にとって重要なのは解数評価ではなく、同論文の
  Type I / Type II 分類の方である**（§8.1）。
- (K4) Schinzel 仮説 H（素数 k-tuples）を仮定すると予想が従うという folkloric
  主張（記憶・未照合のまま。§5 で本理論の言葉で再説明する）。
- (K5) 計算検証が 10^14 を超える範囲で済んでいる（claim カード記載）。

**検証済みの初等的補題（本セッションで証明）:**

**補題 1.2（スケーリング帰着）.** d ≥ 2 かつ S(d) なら、任意の m ≥ 1 で
S(dm)。よって最小反例は素数である。
証明: 4/d = 1/x+1/y+1/z ⟹ 4/(dm) = 1/(mx)+1/(my)+1/(mz)。強い帰納法。∎

**補題 1.3（p | xyz）.** p 素数、4/p = 1/x+1/y+1/z なら p | xyz。
証明: 4xyz = p(xy+xz+yz)。∎

以下、p は奇素数、解は変数の置換を自由にする。

## 2. 補題連鎖

### 2.1 SFFT パラメタライズ（補題 2.1）

p-divisible な変数を z とし z = pz' と書く（補題 1.3）。このとき

  4/p − 1/(pz') = (4z'−1)/(pz') = 1/x + 1/y

の右辺が2項展開可能である条件は、Simon の factoring trick により

  ((4z'−1)x − pz')·((4z'−1)y − pz') = p²z'²   (★)

と同値。m := 4z'−1、a := mx−pz'、b := my−pz' と置くと、解 ↔ 因子対
(a,b)（a·b = p²z'²、a ≡ b ≡ −pz' (mod m)、x = (a+pz')/m 等）。
a = p^i·σ、b = p^{2−i}·τ（σ·τ = z'²、i ∈ {0,1,2}）と分解する。

### 2.2 中間分岐の消滅（補題 2.2）

**補題 2.2.** gcd(p, m) = 1 なら i = 1 な解は存在しない。
証明: 条件 p·σ ≡ −pz'、p·τ ≡ −pz' (mod m) を p で割ると σ ≡ τ ≡ −z' (mod m)。
σ > 0, τ > 0 の場合: σ = km − z'、τ = ℓm − z'（k, ℓ ≥ 1）と書けて
σ·τ = z'² に代入すると kℓm = z'(k+ℓ)。一方 m = 4z'−1 ≥ 3z' なので
z' = kℓm/(k+ℓ) ≥ 3kℓz'/(k+ℓ)、すなわち k+ℓ ≥ 3kℓ。しかし 3kℓ − k − ℓ > 0
（k=ℓ=1 で 1、以後単調増加）で矛盾。σ < 0, τ < 0 の場合: |σ| = km+z'、
|τ| = ℓm+z' と書けて (km+z')(ℓm+z') = z'² の左辺 > z'² で矛盾。∎
（数値確認: p ≤ 48 の全解 151 個で中間分岐使用例なし。）

### 2.3 構造二分（定理 A — 本成果の中心）

**定理 A.** p 素数、(x,y,z) ∈ Sol(p) とする。p-divisible スロット z = pz'
（m = 4z'−1）について、次の二分が成り立つ:

- **(D) 退化族**: p | m。
- **(G) 一般族**: p ∤ m かつ ∃ σ | z'²: m | σ + pz'。
  このとき σ ≡ −pz' (mod m) が i ∈ {0,2} 分岐の正確な条件であり、
  τ = z'²/σ 側の条件 p·τ ≡ −z' (mod m) は σ の条件から自動的に従う
  （τ ≡ z'²·σ^{−1} ≡ −z'p^{−1} (mod m)、gcd(σ,m) = gcd(pz',m) = 1 を使用）。

逆に各族の条件から解が構成できる（§2.4）。
証明: §2.1 の分解で i=1 が補題 2.2 で消え、i ∈ {0,2} は p で割って
σ ≡ −pz' (mod m) を与える。∎
（数値確認: p ≤ 48 の全解 151 個で二分成立、失敗 0。内訳 D:104, G:47。）

### 2.4 逆構成（補題 2.4 — 各族の明示恒等式）

**(G) の逆構成.** σ | z'²、m | σ+pz'、p ∤ m とする。τ := z'²/σ と置くと
p·τ ≡ −z' (mod m) が成り立ち、

  x := (σ + pz')/m,   y := p(p·τ + z')/m,   z := pz'

は整数解である（(mx−pz')(my−pz') = σ·p²τ = p²z'² で SFFT 逆復元、
1/x+1/y = m/(pz') を確認）。

**(D) の完全特徴付け（補題 2.5）.** p | m のとき j := m/p と置くと、
(★) は σ = jx − z'、τ = jy − z'（自動的に σ ≡ −z' (mod j)）と書け、
解の存在と

  ∃ k, ℓ, j ≥ 1:  p·j = 4z'−1 かつ j·k·ℓ = z'·(k+ℓ)

が同値である。このとき (x,y,z) = (k, ℓ, pz')（の置換）であり、検算は
1/k + 1/ℓ = (k+ℓ)/(kℓ) = j/z'、全体で j/z' + 1/(pz') = (jp+1)/z' = 4/p。
（数値確認: p ≤ 31 の D 族解 60 個で jkℓ = z'(k+ℓ) 成立、失敗 0。）

**系 2.6（単純な十分条件）.** 任意の g, K, L ≥ 1 について
4·g·K·L = p(K+L) + 1 ならば (gK, gL, pgKL) は解。
（補題 2.5 の j = K+L、k = gK、ℓ = gL、z' = gKL の場合。）

### 2.5 族 G の線形テンプレート階層（補題 2.7）

族 G の条件 m | σ + pz' は σ の取り方ごとに「p の線形式の約数条件」に落ちる:

- **σ = 1**: m | pz'+1 ⟺ m | p+4。よって「p+4 が ≡ 3 (mod 4) の約数を
  持つ」ことが十分（z' = (m+1)/4 が自動で整数）。
- **σ = z'²**: m | z'(p+z') ⟺ m | 4p+1。よって「4p+1 が ≡ 3 (mod 4) の
  約数を持つ」ことが十分。
- **一般に σ = z'w（w | z'）**: m | z'(p+w) ⟺ m | p+w。d := m と読むと、
  **(F1): ∃ w ≥ 1: p+w が d ≡ −1 (mod 4w) の約数 d を持つ**
  という形にまとめられる（d = 4z'−1、w | z' が復元条件）。

数値確認（p < 2000 の素数 302 個）: σ=1 経路で 232 個、σ=z'² 経路で 174 個、
合併 271 個が解消。残り 31 個（13, 37, 61, 97, … と例外類外のものを含む）
はより深い σ パターンが担当する — 階層は単一の線形経路では閉じない。

## 3. 6例外類の正体 — 帰納が破綻する正確な位置

### 3.1 被覆の意味論

「剰余類 r (mod 840) がテンプレートで解ける」ためには、進数 {r + 840t} が
テンプレート類の合併に**含まれる**必要がある。単一類 c (mod m) が
r (mod 840) を含む ⟺ **m | 840 かつ r ≡ c (mod m)**。m と 840 が互いに素
だと単一類では絶対に被覆できない（進数が類を横切る）。これが
「境界付きパラメータのテンプレート合併」に本質的な限界を課す。

### 3.2 小 modulus 族 G クラスの合併（計算による確認）

m = 4z'−1 | 840 となるのは m ∈ {3, 7, 15, 35}（z' = 1, 2, 4, 9）のみ。
各 z' で σ | z'² の類 c ≡ −σz'^{−1} (mod m) を全部集めると:

- mod 3: {2}
- mod 7: {3, 5, 6}
- mod 15: {7, 11, 13, 14}
- mod 35: {23, 26, 31, 32, 34}

この合併に落ちない 840 の単元は **24 個**残り、
{1, 79, 109, 121, 151, 169, 211, 289, 319, 331, 361, 379, 421, 499, 529, 541,
571, 589, 631, 709, 739, 751, 781, 799} — **6例外類 {1, 121, 169, 289, 361, 529}
の真の超集合**。例外類は「r ≡ 1 (mod 24)、r ≡ ±1 (mod 5)、r は mod 7 の
平方剰余」という二次的構造を持ち、小さい m の類がすべてこの構造と衝突する。

これが (K1) の Mordell 型検証の正体である: 帰納・テンプレート法は
「複雑さが境界付きの σ パターン（＝p の固定線形式の固定類の約数条件）」で
動いており、その各レベルで被覆できない類の核が上記の二次構造として
不変に残る。**破綻点はここ**: 境界を外して σ（や w, z'）を p に応じて
動かすと個々の素数はすぐ解けるが（次節）、その存在を「類に対して一様に」
言う手段が解析的数論に存在しない。

### 3.3 例外類でも個別には解ける（予想 H* の反証）

事前に登録した安い反証テストの結果:

- **予想 H***（反証前に登録）: 「素数 p が族 G 解を持つ ⟺ p mod 840 ∉ 6例外類」。
- 反証テスト1（前方）: 例外素数 p ≤ 10000（27個: 1009, 1129, 1201, 1801,
  2521, …, 9769）全員が z' ≤ 100000 で族 G 解を持つ → **H* 反証**。
  最小 z' は驚くほど小さい: 1009→3, 1129→3, 1201→8, 1801→3, 2521→12,
  2689→6, 3049→11, 3361→25。
- 反証テスト2（後方）: 非例外素数 p ≤ 400（77個）は全員 z' ≤ 20000 で
  族 G 解を持つ（最小 z' の中央値 1、最大 11）→ こちらは H* と整合。

例: p = 1009 は 4p+1 = 4037 = 11·367 の 11 ≡ 3 (mod 4) が σ=z'² 経路を、
p+w = 1012 = 4·11·23 の 11 ≡ −1 (mod 4·3) が F1 (w=3) 経路を通る。

**結論: 6例外類の「抵抗」とは、個別可解性ではなく、境界付き複雑さの
テンプレート（固定線形式・固定類・固定 modulus）では進数全体を被覆できない
という一様性の欠如である。** 既知の密度1証明（K2）がこの階層を平均で押し
進められるのに対し、最後の6類は「どの有限レベルでも被覆されない」という
二次剰余の不変量として残る。

### 3.4 族 D の側から見た例外類

族 D（系 2.6 型の証明書）は逆に、例外素数に対してパラメータの大きい証明書を
与える傾向がある（g ≤ 600 探索）: 1009 → (g,L,K) = (23, 11, 3700)、
1801 → (41, 11, 6604)、3361 → (29, 29, 32490) と K/p が 3.7〜9.7 に達する
一方、1129, 1201, 2521, 2689, 3049 は g ≤ 600 で証明書なし。族 D の条件
4gKL = p(K+L)+1 は小 modulus に対して周期的でないため、剰余類帰納の
「被覆」の枠組みにそもそも乗らない — 例外類を救済する力はあるが
一様化できない。

## 4. 破綻点の正確な記述

定理 A により、E-S は次と同値である:

> **(†)** すべての素数 p ≥ 3 について、
> (i) ∃ z', σ: σ | z'² ∧ (4z'−1) | (σ + pz')、または
> (ii) ∃ k, ℓ, j: (k+ℓ) | jkℓ ∧ p = (4jkℓ − k − ℓ)/(j(k+ℓ))。

**破綻点: (†) の全称文。** 具体的には、6例外類の素数に対する (i)/(ii) の
存在証明ができない。既存手法が通らない理由:

1. **Dirichlet / Linnik**（固定 AP の素数）: (i) で必要なのは「modulus
   4z'−1 が自由パラメータと共に動き、かつ目標類 −σz'^{−1} が同じパラメータで
   決まる」配置。固定 modulus の理論は適用できない。
2. **Bombieri–Vinogradov**: 類に関する平均は modulus ≤ X^{1/2} まで。
   ここでは modulus が探索自由変数そのもの（≈ X オーダーで動く）なので
   「X に対するレベル X^{1/2}」の枠組み自体が定義しない。
3. **Titchmarsh 型平均**（τ(pL+1) の平均）: 約数の**個数**の平均は出るが、
   約数が「modulus に対する指定類」に入るという制約は平均から落ちる。
4. **Iwaniec 型ふるい**（二次多項式の約数）: 多項式が固定であることが前提。
   σ | z'² という乗法制約と 4z'−1 | σ+pz' という合同制約の三重連動は扱えない。
5. **帰納・テンプレート法（Mordell 型）**: §3.2 の通り、境界付き複雑さでは
   6類が二次剰余の不変量として残る。境界を外すと一様性を失う。

つまり (†) は「動く modulus・動く類・動く乗法制約」の三重連動した
約数存在問題であり、現行の解析的道具はいずれもこの三重連動を扱えない。
これが「density-1 は証明できるのに最後の類が立ちはだかる」構造的理由。

**注意（(†) の範囲）.** (†) と E-S の同値性は成立する。(†)(i) は族 G の
条件そのもの（σ は `σ | z'²` を走る一般の約数）、(ii) は補題 2.5 の族 D
であり、定理 A が二分の網羅性を、補題 2.4/2.5 が逆構成を与えるからである。
一方 §5 の NL は (†)(i) を σ = z'w の部分族に制限したものなので、
**(†) の同値性は NL には引き継がれない**。§5 を参照。

## 5. 最小の新補題

**NL（F1/F2 存在補題）.** 各 r ∈ {1, 121, 169, 289, 361, 529} と
素数 p ≡ r (mod 840) について、次の少なくとも一方が成り立つことを示せ:

- **(F1)** ∃ w ≥ 1: p+w が d ≡ −1 (mod 4w) の約数 d を持つ
  （族 G の σ = z'w サブファミリー）。
- **(F2)** ∃ k, ℓ, j ≥ 1: (k+ℓ) | jkℓ かつ p = (4jkℓ−k−ℓ)/(j(k+ℓ))
  （族 D）。

NL が証明されれば E-S は（補題 1.2 + 定理 A + 補題 2.4/2.5 により）解決する。
**この方向 `NL ⇒ E-S` のみが成立する。**

### 5.1 訂正: NL は E-S と同値ではない（2026-08-23）

初版はここで「逆に NL の反証は E-S の反証を与える。すなわち NL は E-S と
同値な強さ」と書いていた。**これは誤りである。** 訂正の内容を残す。

定理 A が与える族 G の条件は `∃σ: σ | z'² ∧ m | σ + pz'` であり、σ は z'²
の**任意の**約数を走る。一方 F1 は §2.5 で導いたとおり `σ = z'w`（w | z'）
の場合だけを扱う。`σ | z'²` の約数がすべて z'w の形になるわけではない
（例: z' = 6, z'² = 36 に対し σ = 4 は 6w の形ではない）。したがって

  F1 の族 ⊊ 族 G

であり、`E-S ⇒ NL` を言うには「一般の族 G 解を必ず F1 型の解へ移せる」という
exhaustion lemma が別途必要になる。本文書にその証明は無い。よって
**NL は E-S より真に強い可能性のある主張**であり、NL の反証は E-S の反証を
与えない。

さらに、この漏れは軽微ではない。§2.5 で「p < 2000 の素数 302 個中 232 個を
解消する」と評価した σ = 1 経路（`m | p+4`）は、z' > 1 のとき F1 に**含まれ
ない**（σ = 1 が z'w の形になるのは z' = 1 のときのみ）。F1 が拾えるのは
σ = z'² 経路（w = z'）の側である。

数値確認（`aux_check.py` CHECK 6）: p < 200 の素数 41 個について、族 G の
条件を満たすが σ が z'w 形でない witness が実在する。最小のものは
(p, z', m, σ) = (7, 3, 11, 1), (11, 4, 15, 1), (17, 2, 7, 1), (37, 4, 15, 2)。

したがって「対象を6類に絞った単一の明示的な約数条件に削ぎ落とした」という
初版の新規性主張のうち、**「削ぎ落としても同値」の部分は撤回する**。残るのは
「NL は E-S の十分条件であり、6類に限定された形をしている」までである。

## 8. 先行研究との関係（2026-08-23 追加）

初版は §1 で「出典は記憶に基づく・本セッションでは未検証」と書いたまま
ROUTE-LIVE を出した。この節はその照合を行った結果である。結論は
**中心的な帰着は既知であり、本文書はその座標変換である**。

### 8.1 族 D / 族 G ＝ Elsholtz–Tao の Type I / Type II

Elsholtz–Tao (arXiv:1107.1010) は素数 n に対する解を、分母のうち n で
割り切れるものがちょうど1個か2個かで **Type I / Type II** に分類し、
奇素数の解がすべてこのどちらかであることを示したうえで、それぞれに
完全なパラメータ表示を与えている。同論文はさらに、既知のパラメータ表示群を
6次元アフィン空間内の3次元多様体の座標の取り替えとして統一している。

本文書の定理 A は、p-divisible なスロットを z = pz' と置いて
`p | 4z'−1`（族 D）と `p ∤ 4z'−1`（族 G）に分けるものであり、解を復元すると
この Type I / Type II の切り分けに一致する。**「全解が D か G のどちらか」は
新しい構造定理ではない。**

### 8.2 族 G の約数条件 ＝ Bradford の条件（消去するスロットが違うだけ）

Bradford, *Elementary Patterns from the Erdős–Straus Conjecture*
(Integers, 2021) は、素数 p に対し

  ∃x, ⌈p/4⌉ ≤ x ≤ ⌈p/2⌉ かつ ∃d | x²:
    d ≡ −px (mod 4x−p)、または（d ≤ x かつ d ≡ −x (mod 4x−p)）

という divisor + congruence 条件を立て、その解が E-S の解と一対一対応する
ことを証明している。

本文書の族 G は `σ | z'²` かつ `σ ≡ −pz' (mod 4z'−1)` である。両者の関係は
どちらのスロットを先に消去するかの違いに尽きる:

- 本文書: p-divisible スロット z = pz' を消去 →
  1/x + 1/y = (4z'−1)/(pz') → SFFT で (Mx−pz')(My−pz') = p²z'²、M = 4z'−1
- Bradford: p で割れないスロット x を消去 →
  1/y + 1/z = (4x−p)/(px) → SFFT で (M'y−px)(M'z−px) = p²x²、M' = 4x−p

どちらも `(M·u − pv)(M·w − pv) = p²v²` という同一形で、約数条件は
`d | v²` かつ `d ≡ −pv (mod M)`。本文書の (v, M) = (z', 4z'−1)、Bradford の
(v, M) = (x, 4x−p) である。Bradford の第2条件（d ≤ x, d ≡ −x）は p で
割る側の分岐に対応し、本文書では補題 2.2 の i ∈ {0,1,2} 分岐に対応する。

数値確認（`aux_check.py` CHECK 7）: p < 200 の全素数で両条件の可解性判定は
完全に一致する。ただし**この一致自体は新規性の否定にも肯定にもならない**
（両方とも E-S(p) と同値なので一致は自明）。根拠は上の代数的対応の方である。

さらに、2026-06-09 に arXiv:2606.10922 (Bello-Hernández ら,
*A Divisor Parametrization for the Erdős–Straus Conjecture*) が
divisor ベースの関数 `fab(n,a,b)` で分解を過不足なく復元する completeness
定理を証明し、**それを Type I/II 記述と明示的に比較している**。本文書の
初版 PR (2026-08-22) の約2か月前である。

### 8.3 6例外類の obstruction も既知の構造

6例外類 {1, 121, 169, 289, 361, 529} (mod 840) は
{1², 11², 13², 17², 19², 23²} であり、これは偶然ではない。Elsholtz–Tao は
**奇数 n に対して n² は Type I 解も Type II 解も持たない**ことを示しており、
有限個の合同被覆戦略が失敗する理由をこの平方数 obstruction に帰している。
§3.2 が「二次剰余の不変量として残る」と述べた現象は、この既知の obstruction
の別表現である。

## 9. (M0)/(M1) の解決と τ 正規形（2026-08-23 追加）

§5.1 で開いた穴（`E-S ⇒ NL` に exhaustion lemma が要る）を、本リポジトリの
枠組みのまま塞ぎに行った記録。結論は次の3点である。

1. exhaustion lemma (M0) は**偽**。F1 を保ったままでは穴は塞がらない（§9.2）。
2. F1 単独では6例外類を賄えない (M1 は否定的に解決)。F1 判定は**決定可能**
   なので、これは探索打ち切りではなく証明である（§9.1, §9.3）。
3. 穴の正しい塞ぎ方は F1 の拡張であり、それは **τ 正規形**という1つの
   パラメータで書ける（§9.4）。ただしこの τ 正規形は Lopez の公表済み
   合同式系の完全化にあたり、F1 は同系の型 (B) そのものである（§9.5）。
   よって verdict は **ROUTE-KNOWN のまま**変わらない（§9.6）。

### 9.1 補題 F（F1 の決定可能性）

**補題 F.** 素数 p に対し、F1(p) は次と同値である:

> ∃ w with 1 ≤ w ≤ (p+1)/3, ∃ d | (p+w) with d ≡ −1 (mod 4w).

*証明.* F1 の定義（§2.5）は `∃z' ≥ 1, ∃w | z', (4z'−1) | p+w` である。
d := 4z'−1 とおくと d+1 = 4z' なので、`d ≡ −1 (mod 4w)` ⟺ `4w | 4z'` ⟺
`w | z'`。d | p+w と p+w > 0 より
d ≤ p+w。したがって 4w ≤ 4z' = d+1 ≤ p+w+1、すなわち **3w ≤ p+1**。
逆向きは d から z' = (d+1)/4 を作れば定義を満たす。∎

**帰結.** F1(p) は有限手続きで判定できる。以下「F1(p) は偽」と書くとき、
それは打ち切り探索で見つからなかったという意味ではなく、**証明された非存在**
である。数値確認は `aux_check.py` CHECK 8（有界版と素朴版が p < 400 で完全一致）。

補題 F の証明は初等的であり、新規性を主張するものではない。ここで必要なのは、
以下の否定的結果を「証明」の資格で述べられるようにすることだけである。

### 9.2 (M0) は偽 — exhaustion lemma は成立しない

**命題 9.2.** 族 G の解を持ちながら F1 が偽である素数が存在する。

*証明（p = 7）.* 族 G の witness: z' = 3, m = 4·3−1 = 11, σ = 1 は σ | z'² = 9
を満たし、σ + pz' = 1 + 21 = 22 = 2·11 なので m | σ + pz'。
F1 側: 補題 F より w ≤ (7+1)/3 = 2 だけ見ればよい。
w = 1 のとき p+w = 8 の約数は {1,2,4,8}、いずれも ≡ −1 (mod 4) ではない。
w = 2 のとき p+w = 9 の約数は {1,3,9}、いずれも ≡ −1 (mod 8) ではない。
よって F1(7) は偽。∎

p = 31 でも同様（族 G witness は z'=2, m=7, σ=1。w ≤ 10 を尽くして F1 は偽。
`aux_check.py` CHECK 9 に全 10 ケースを出力してある）。

**帰結.** §5.1 の Gate A 破れは「exhaustion lemma を証明する」経路では
修復できない。`E-S ⇒ NL` を回復するには F1 を広げるしかない。
(M0) は cheap falsification の段階を飛ばして**確定的に閉じた**。

### 9.3 (M1) は否定的に解決 — F1 単独では6例外類を賄えない

補題 F により F1 は完全判定できるので、F1 が偽になる素数を尽くせる。

> p < 20000 で F1 が偽の素数（完全決定）:
> **3, 7, 31, 79, 127, 199, 409, 577, 2719, 5569, 8191, 9601**

このうち **p = 5569 ≡ 529 (mod 840)** と **p = 9601 ≡ 361 (mod 840)** は
6例外類に属する。したがって:

**命題 9.3.** F1 だけでは6例外類の素数をすべて賄うことはできない。

これは (M1) の事前登録テスト（「例外素数 p ≤ 10⁶ について w ≤ 10⁴ の証人を
探す」）よりも強い結論である。事前登録テストは「証人が見つからない」ことしか
言えないが、補題 F があるので**証人の非存在が証明される**。

**ただし NL 自体は反証されない。** 5569 と 9601 はどちらも族 D (F2) の解を持つ:

| p | p mod 840 | 族 D 証明書 (4gKL = p(K+L)+1) | 解 |
| --- | --- | --- | --- |
| 5569 | 529 | g=706, K=141, L=2 | (99546, 1412, 1108743348) |
| 9601 | 361 | g=1265, K=37, L=2 | (46805, 2530, 898749610) |

（`aux_check.py` CHECK 9b。恒等式 4xyz = p(xy+xz+yz) を assert で確認済み。）

つまり NL = F1 ∨ F2 は生き残るが、**これらの素数では NL の根拠は F2 側にしか
無い**。F1 は「6類への攻撃の主役」ではありえない。

観察（証明なし）: 12個の失敗素数はすべて p+1 = 2^a · ∏(q ≡ 1 mod 4) の形を
持つ。これは w = 1 が失敗する条件そのもので**必要条件**だが十分ではない
（p < 20000 に該当する素数は 350 個、うち実際に F1 が落ちるのは 12 個）。
また Mersenne 素数 3, 7, 31, 127, 8191 が全て失敗リストに入っているが、
8191 より先は未検証であり、パターンとして主張しない。

### 9.4 τ 正規形 — 穴の正しい塞ぎ方

**補題 9.4（正規形）.** m = 4z'−1、gcd(m, p) = 1 とする。σ | z'² に対し
τ := z'²/σ とおくと

> m | σ + p z'   ⟺   m | 4 p τ + 1.

*証明.* 4z' ≡ 1 (mod m)。よって 4τσ = 4z'² = z'·(4z') ≡ z' (mod m)。
両辺に 4τ を掛けて
4τ(σ + p z') = 4τσ + 4pτ z' ≡ z' + 4pτ z' = z'(1 + 4pτ) (mod m)。
gcd(z', m) = gcd(z', 4z'−1) = 1、τ | z'² より gcd(τ, m) = 1、gcd(4, m) = 1。
したがって m | σ + pz' ⟺ m | 4pτ + 1。∎

**定理 A′（τ 版・穴なし）.** 素数 p について E-S が成り立つことは、次と同値:

> ∃ z' ≥ 1 で、`p | 4z'−1`（族 D）または `∃τ | z'² : (4z'−1) | 4pτ + 1`（族 G）。

これは定理 A と補題 9.4 の合成であり、σ が z'² の約数全体を走ることを τ が
そのまま引き継ぐので、§5.1 が指摘した exhaustion gap を持たない。

**補題 9.4b（穴の一行表現）.** この座標で

> **F1 ⟺ τ | z'**、  一方 **族 G ⟺ τ | z'²**。

*証明.* F1 は σ = z'w（w | z'）。このとき τ = z'²/σ = z'/w であり、w | z' より
τ | z'。逆に τ | z' なら w := z'/τ は z' を割り、σ = z'² /τ = z'w。∎

したがって §5.1 の「NL は E-S より真に強い可能性がある」という状況は、
**`τ | z'` と `τ | z'²` の差**という一行に集約される。数値確認は
`aux_check.py` CHECK 10（11909 組の (p, z') で補題 9.4・9.4b とも不一致 0）。

τ の3つの特別値は §2.5 の線形テンプレート階層に対応する:

| τ | 条件 | §2.5 での呼び名 |
| --- | --- | --- |
| 1 | m \| 4p+1 | σ = z'² 経路 |
| z' | m \| p+1 | σ = z' 経路 |
| z'² | m \| p+4 | σ = 1 経路 |

（導出は 4z' ≡ 1 (mod m) の反復適用。τ = z' のとき 4pτ+1 = 4pz'+1 ≡ p+1。
τ = z'² のとき 4pz'²+1 = p·z'·(4z')+1 ≡ pz'+1、これに 4 を掛けて
4pz'+4 ≡ p+4 で、gcd(4, m) = 1 より m | p+4 と同値。）

### 9.5 Gate B — τ 正規形は Lopez の合同式系の完全化である

> Miguel Angel Lopez, *A Complete Congruence System for the Erdős–Straus
> Conjecture*, arXiv:2404.01508 (v1 2024-04-01, v3 2024-04-15).

同論文は m = 4dn−1 (d, n ≥ 1) に対する3つの合同式を立て、そのいずれかが
全素数で成り立つと予想している:

> (A) p ≡ −4d (mod m)、 (B) p ≡ −n (mod m)、 (C) p ≡ −4d² (mod m)。

4dn ≡ 1 (mod m) を使うと (A) ⟺ m | pn+1、(C) ⟺ m | pn+d と書き換えられる。
z' := dn とおいて補題 9.4 の座標に移すと:

| Lopez の型 | 条件 | τ 正規形 |
| --- | --- | --- |
| (A) | p ≡ −4d (mod m) | τ = d n² |
| **(B)** | **p ≡ −n (mod m)** | **τ = d** |
| (C) | p ≡ −4d² (mod m) | τ = n² |

（`aux_check.py` CHECK 10 で d, n ≤ 24 × p < 300 の全組み合わせにつき
不一致 0。3つの τ はいずれも z'² = d²n² の約数である。）

**帰結 1（本文書にとって決定的）: F1 は Lopez の型 (B) そのものである。**
z' = dn, w = n（したがって τ = d | z'）と読めば完全に一致する。
すなわち §5 で「最小の新補題」として立てた F1 は、2024年4月に公開済みの
条件であり、新規ではない。§8.4 に残していた未確認事項はこれで解消した。

**帰結 2: Lopez の系は τ 正規形への制限である。** {d, n², dn² : dn = z'} は
一般に div(z'²) を尽くさない。最小の欠落は z' = 12 で、div(144) の 15 個の
うち τ = 8 と τ = 18 が Lopez の系では到達できない（z' = 18, 20, 24 でも
同様。CHECK 10）。したがって Lopez の予想「(A)∨(B)∨(C) が全素数を覆う」は
E-S より**真に強い**主張であり、逆に定理 A′ の τ 正規形は E-S と**ちょうど
同値**な完全版にあたる。

**事前登録テスト（CHECK 11、実行前に閾値を固定）:** p < 20000、z' ≤ 300 で
「τ 正規形は成立するが Lopez の3つの τ はどれも効かない」(p, z') を探す。
どの z' でもそうなる素数が1つでもあれば Lopez の予想は反証される。

> 結果: そのような (p, z') レベルは **4426 組**存在する（τ 正規形はレベル
> ごとには真に広い）が、**全レベルで Lopez が効かない素数は無い**。
> Lopez の予想はこの範囲で反証されない。
